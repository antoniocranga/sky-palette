Sky Palette v1.0.0

Physical sky colour engine & solar architecture

Sky Palette computes five-swatch sky palettes (Zenith, Mid-Sky, Horizon, Sun Glow, Cloud Tint) from solar geometry, live cloud layers and visibility. Community photos stay anonymous and are reviewed before publication.

GitHub Repository

Core Technologies

Hermite sky model
C¹-continuous interpolation across solar elevation anchors, modulated by cloud cover and visibility.
NOAA / Meeus solar geometry
Solar elevation, azimuth, sunrise, sunset and golden-hour calculation by latitude and longitude.
Open-Meteo weather
Live low, mid and high cloud cover plus visibility, without API keys.
OpenStreetMap place names
Photo GPS is reverse geocoded on the server, so the upload can suggest the nearest town. © OpenStreetMap contributors.
Vite + TypeScript
One hashed bundle, self-hosted fonts, Canvas export and CSS Grid. No third-party runtime requests.
Cloudflare D1 & R2 Storage
Serverless SQLite for palettes and private object storage for reviewed community photos.
Cloudflare Edge & Analytics
Edge compute, image moderation, Turnstile bot checks and cookie-free Web Analytics.

Usage Monitoring & Telemetry

Cloudflare Web Analytics (Privacy-First)

To monitor application health, traffic volume, and performance (such as Largest Contentful Paint and interaction responsiveness), Sky Palette utilizes Cloudflare Web Analytics.

  • Zero Cookies: No cookies or client-side storage are ever set or read for telemetry.
  • Zero Fingerprinting: No device fingerprints, canvas hashes, or cross-site tracking IDs.
  • Zero Personal Data: IP addresses are never logged or stored. Aggregate metrics only.
  • GDPR & ePrivacy Compliant: Does not require consent banners because no personal data is processed.

Privacy & Cookies

100% Cookie-Free

Sky Palette is built on strict data minimalism:

No User Accounts: Anyone can explore palettes and submit photos anonymously.
Zero Cookies: No database or session cookies. Cloudflare D1 and Workers operate via edge bindings without tracking.

Release Notes

v1.0.0 · Initial launch November 2026
  • Worker API for palettes, 15/30-day history, geocoding, gallery, config and dynamic OG cards.
  • Shared solar, C1 palette, WCAG colour and timezone engines used by both Worker and browser.
  • Live Open-Meteo cloud layers and per-day sunset palettes cached at the edge.
  • Turnstile-protected photo submissions with server-side metadata stripping, private R2 storage and pending review.
  • Typed modular client with real data, local scrub computation and Canvas share cards.
  • Mobile dvh layout with safe-area insets, focus-trapped dialogs and WCAG 2.2 AA checks.
